# YOYO Language

A full-desi, slang-powered programming language with a real Node.js CLI.

## Run

```bash
npm install -g yoyo-lang
yoyo program.yoyo
```

Or from the source tree:

```bash
npm install
npm run build
node bin/yoyo.js examples/hello.yoyo
```

YOYO files use the `.yoyo` extension and can be edited in any text editor, including VS Code, without an extension.
